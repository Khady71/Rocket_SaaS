# 🎓 SaaS Associations - Mini-Wordpress de générations de sites vitrines d’associations étudiantes

## 🧩 Description du projet
Ce projet vise à créer une plateforme SaaS permettant aux associations étudiantes de créer et gérer leur site web facilement. Les administrateurs peuvent présenter l’association, gérer les membres, publier des annonces et proposer des activités avec inscription en ligne.

> **État actuel** :  
> - Backend : Authentification via Spring Security + CRUD pour Associations, Users, Activités.
> - Frontend : Page de login fonctionnelle  

Le projet est en cours de développement.

---

## 🎯 Objectifs du projet
- Monter en compétences en Java avec **Spring Boot** (backend) et **Angular** (frontend).  
- Déployer et gérer le projet sur le cloud.  

---

## 👥 Public cible
- Associations étudiantes.  
- Clubs, ONG, collectifs étudiants ou culturels.  

---

## 🧠 Valeur ajoutée
- Création automatique et personnalisable du site web de l’association.  
- Interface admin centralisée pour gérer activités, annonces, bureau.  
- SaaS multitenant : chaque association a son propre espace.  
- Possibilités futures : réservation d’événements, paiement en ligne, CRM simple.
